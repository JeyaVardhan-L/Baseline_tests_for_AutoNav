# Results

## Purpose

Aggregated results from all experiments. Presentation-quality figures, summary tables, and reports are collected here for easy reference and stakeholder presentation.

## Structure

```
results/
├── README.md       # This file
├── figures/        # Presentation-quality plots from experiments
├── tables/         # Summary tables (CSV)
└── reports/        # Aggregated analysis reports
```

## Convention

- Only **final/presentation-quality** outputs go here
- Working outputs stay in `experiments/*/results/` and `experiments/*/figures/`
- Every figure must have: title, axis labels, units, legend, source annotation
- Every table must be machine-readable (CSV)

# Simulation

## Purpose

This directory will contain simulation environments and scenarios for testing the autonomous navigation stack in a virtual environment before flight testing.

## Planned Approach

Candidates for simulation:

- **Gazebo** (ROS 2 integration)
- **AirSim** (Microsoft, Unreal Engine)
- **PX4 SITL** (Software-In-The-Loop with PX4 firmware)

## Status

**NOT YET IMPLEMENTED.** Simulation is planned for Phase 3.

## Dependencies

- Phase 2 (navigation algorithms) must be implemented first
- ROS 2 integration may be required

# Benchmarks

## Purpose

This directory will contain hardware performance benchmarks (CPU, GPU, memory, latency, power) for candidate onboard computing platforms.

## Planned Structure

```
benchmarks/
├── README.md       # This file
├── cpu/            # CPU benchmark results
├── gpu/            # GPU benchmark results
├── memory/         # Memory bandwidth and usage benchmarks
├── latency/        # Processing latency measurements
└── power/          # Power consumption measurements
```

## Status

**NOT YET POPULATED.** Benchmarks will be created during EXP-09 (Compute Benchmark).

## Dependencies

Benchmarks require:

1. Completion of experiments EXP-01 through EXP-08 to define the workload
2. Access to candidate hardware (or equivalent) for benchmarking

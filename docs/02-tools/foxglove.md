# Foxglove: Modern Robotics Data Visualization

## Why Does Foxglove Exist?

Historically, ROS developers relied on `RViz`—a desktop C++/Qt tool that was notoriously difficult to install on Windows or macOS and required an active X11 display server.

**Foxglove Studio** is a modern, high-performance web and desktop visualization tool built for robotics.

---

## 1. Key Capabilities

1. **Native Cross-Platform**: Runs natively on Windows, macOS, Linux, and modern web browsers.
2. **Direct MCAP Support**: Opens `.mcap` and ROS 2 bag files directly without needing a running ROS 2 core daemon or middleware installation.
3. **Multi-Panel Layouts**: Visualizes 3D point clouds, camera streams, IMU telemetry graphs, and diagnostic logs side-by-side in real time.
4. **Custom Panels**: Supports user-written TypeScript/React panels for telemetry inspection and trajectory error evaluation.

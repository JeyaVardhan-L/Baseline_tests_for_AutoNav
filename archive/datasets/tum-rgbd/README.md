# TUM RGB-D Benchmark Directory

Place downloaded TUM RGB-D sequences in this directory.

**Official Download Page**: [https://vision.in.tum.de/data/datasets/rgbd-dataset/download](https://vision.in.tum.de/data/datasets/rgbd-dataset/download)  
**Recommended Beginner Sequence**: `rgbd_dataset_freiburg1_xyz`

Expected structure:
```
datasets/tum-rgbd/
    rgbd_dataset_freiburg1_xyz/
        rgb/
        depth/
        groundtruth.txt
        accelerometer.txt
        depth.txt
        rgb.txt
```

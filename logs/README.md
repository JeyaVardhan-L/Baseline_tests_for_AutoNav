# Logs

## Purpose

Execution logs from experiment runs. Logs capture timestamped records of what was run, when, and with what parameters.

## Convention

- Log filenames include the experiment ID and timestamp: `exp01_20261007_153045.log`
- Large log files are excluded from Git (see `.gitignore`)
- Critical findings from logs should be recorded in the experiment's README

## Status

Logs will be generated automatically when experiments are run.
